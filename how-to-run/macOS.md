this os has quite strict enforcements when it comes to apps, so your experience might be quite poor. if after trying these steps you can't get the mod loader to work, i invite you to get rid of it and install mods the traditional way instead (by visiting their official websites or discord threads).

### after downloading the MacOS release of the mod loader, pls follow these steps to maximize your chances of being able to run it.

1. grab the app and move it to your Applications folder. this will extract it from the zip.
2. once there, right click on it and choose 'Open'.
3. a popup should appear, choose 'Open' again.
TIP: if the popup has no 'Open' option, go to your System Preferences -> Security & Privacy -> General, and click 'Open Anyway'.
4. if the app opens, you should now be able to install games. 'Launch' might still not work though because an app launching another process is scary for Apple, in which case please use Extras -> Open in file explorer..
